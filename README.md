# prelum/.github

Default community files for every repository in the [prelum](https://github.com/prelum) organization.

- `FUNDING.yml`: the Sponsor button.
- `CONTRIBUTING.md`: how to set up, check and propose changes.
- `SECURITY.md`: how to report a vulnerability privately.
- `ISSUE_TEMPLATE/`: the bug report and idea forms.
- `profile/README.md`: the introduction on [github.com/prelum](https://github.com/prelum).
