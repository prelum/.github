Prelum turns Markdown into PDFs that look designed: a cover, running headers, "Page 2 of 4", Mermaid diagrams and tables that break cleanly. Pick a theme in the frontmatter, never write CSS. Open source, MIT, works offline.

```sh
npx prelum report.md
```
